# BRFSS Obesity and Inactivity Analysis (2011–2012)

## Project Overview
This project analyzes trends in physical inactivity and obesity across U.S. states using data from the Behavioral Risk Factor Surveillance System (BRFSS) for the years 2011 and 2012. The analysis explores correlations between inactivity and obesity rates and visualizes trends across random states and specific U.S. regions.

## Files Included
- BRFSS_dataset.csv — Raw dataset used for analysis
- Final_Project.ipynb — Jupyter Notebook with all code, visualizations, and findings
- README.txt — This file
- Requirements.txt

## Key Features
- National average trends for inactivity and obesity
- Correlation analysis between inactivity and obesity
- State-wise trend visualization for 13 random states
- Region-wise comparisons (Northeast, Southeast, Southwest, Northwest)

## How to Run
1. Open `Milestone 02_jdhingra.ipynb` in Jupyter Notebook or VS Code.
2. Make sure `BRFSS_dataset.csv` is in the same directory.
3. Make sure you change the location of file saved on your device to load data.
4. Run the notebook from top to bottom to reproduce all plots and outputs.

## Requirements
- Python 3.x
- pandas
- matplotlib
- seaborn
